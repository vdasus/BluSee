# План разработки: Bluetooth Battery Monitor in Windows Tray

## Стек технологий
* **Платформа:** .NET 10+ (C# 14)
* **Target Framework:** `net10.0-windows10.0.19041.0` (используем TFM с поддержкой Windows SDK для прямого доступа к WinRT APIs)
* **Тип приложения:** Windows Forms / WPF (без отображения основного окна, только Tray Icon) или Worker Service с интеграцией `System.Windows.Forms.NotifyIcon`
* **API Windows:** Windows Runtime (WinRT) APIs (`Windows.Devices.Bluetooth`, `Windows.Devices.Enumeration`)

---

## Этап 1: Исследование и Прототипирование (Быстрый MVP)
**Цель:** Научиться получать заряд батареи хотя бы одного подключенного устройства и вывести его в консоль/лог.

1. **Создание проекта:**
   * Консольное приложение или библиотека с TFM `net10.0-windows10.0.19041.0` (минимальная версия Win10 2004, полностью совместимо с Win11).
2. **Запросы к WinRT API для поиска устройств:**
   * Использование `DeviceInformation.FindAllAsync` со специфичным AQS (Advanced Query Syntax) фильтром для Bluetooth устройств.
   * Проверка свойства `System.Devices.Aep.ProtocolId` для фильтрации Bluetooth Classic и BLE.
3. **Извлечение уровня заряда:**
   * **Для BLE (Bluetooth Low Energy):** Запрос к GATT-сервису Battery Service (`GattDeviceService.GetSelectorFromUuid(GattServiceUuids.Battery)`), чтение характеристики `BatteryLevel` (`0x2A19`).
   * **Для Bluetooth Classic (мыши, клавиатуры):** Чтение свойств из `DeviceInformation.Properties`. В Windows 10 (1809+) и Windows 11 свойства батареи часто кэшируются ОС в Advanced Query Syntax (AEP) свойствах:
     * `System.Devices.BatteryLevel` (GUID: `{104EA319-6EE2-4701-BD47-8D0F1493C853}`, ID: `9`)
4. **Консольный MVP:**
   * Вывод списка всех спаренных HID-устройств (клавиатуры, мыши, гарнитуры) и текущего процента заряда в цикле.

---

## Этап 2: Создание фонового процесса и Tray-инфраструктуры
**Цель:** Перенос логики в фоновое приложение Windows с иконкой в трее.

1. **Настройка жизненного цикла приложения:**
   * Использование `ApplicationContext` из WinForms или скрытого окна WPF, чтобы приложение работало в фоне без таскбара (`ShowInTaskbar = false`).
2. **Инициализация NotifyIcon:**
   * Создание иконки в системном трее.
   * Добавление базового контекстного меню (выход, принудительное обновление).
3. **Динамические иконки (Render Engine):**
   * Вместо статических картинок — генерация `System.Drawing.Icon` на лету с помощью `Graphics` (рисование цифры процента или шкалы прямо на холсте 16x16 / 32x32 для поддержки DPI Windows 11).
   * Если устройств несколько: отображение иконки с наименьшим зарядом или создание комбинированной логики.

---

## Этап 3: Архитектура фонового мониторинга (Оптимизация процессов)
**Цель:** Обеспечить стабильность, энергоэффективность и реактивность.

1. **Сервис мониторинга (Watcher):**
   * Использование `DeviceWatcher` вместо постоянного polling в бесконечном цикле.
   * Подписка на события `Added`, `Removed`, `Updated` для отслеживания подключения/отключения устройств.
2. **Периодический опрос заряда:**
   * Использование `PeriodicTimer` (.NET 6+) для обновления состояния каждые 10–15 минут (уровень заряда батареи Bluetooth-устройств меняется медленно, частый опрос разряжает само устройство).
3. **Потокобезопасность:**
   * Обработка обновлений от `DeviceWatcher` в фоновых потоках, обновление UI трея через маршалинг в UI-поток (`Invoke`/`Dispatcher`).

---

## Этап 4: Интеграция с ОС и UI/UX (Windows 10 / 11)
**Цель:** Соответствие гайдлайнам Windows 11 и удобство использования.

1. **Дизайн контекстного меню:**
   * Кастомный рендеринг контекстного меню (ContextMenuStrip) с поддержкой темной/светлой темы Windows 11 (через чтение параметров реестра `AppsUseLightTheme`).
   * Отображение списка всех отслеживаемых устройств прямо в меню трея: `[Иконка типа устройства] Имя устройства — XX%`.
2. **Уведомления (Toast Notifications):**
   * При падении уровня заряда ниже 15% — отправка системного уведомления через `Microsoft.Toolkit.Uwp.Notifications` (или нативный `ToastNotificationManager`).
3. **Автозагрузка:**
   * Добавление опции запуска при старте системы (запись в `Software\Microsoft\Windows\CurrentVersion\Run`).

---

## Этап 5: Обработка пограничных случаев (Edge Cases)
1. **Устройство ушло в режим сна:** обработка таймаутов при попытке чтения GATT-характеристик.
2. **Bluetooth отключен на ПК:** подписка на изменение состояния локального радио-адаптера (`BluetoothAdapter.GetDefaultAsync()`), изменение иконки трея на статус "Bluetooth отключен".
3. **Смена DPI/Масштабирования:** корректный пересчет размеров шрифта при отрисовке иконки трея.
